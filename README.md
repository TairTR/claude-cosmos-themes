# Живые фоны для Claude Code: Солнечная система и не только

Мод для десктопного приложения Claude Code: анимированный фон за чатом, который меняется по мере заполнения контекста.

*An animated backdrop mod for the Claude Code desktop app: a Keplerian solar system with Halley's comet, plus four other scenes. The scene changes as the context window fills.*

## Сцены

**Космос** — три вида Солнечной системы:
- **сбоку** — система почти с ребра, в плоскости эклиптики, с зодиакальным светом и поясом астероидов;
- **сверху** — все восемь планет на своих орбитах;
- **внутренние планеты** — от Меркурия до Марса в настоящем масштабе расстояний и пояс астероидов.

Что в них настоящее:
- планеты идут по своим эллиптическим, слегка наклонённым орбитам (законы Кеплера, элементы орбит J2000): у Солнца быстрее, вдали медленнее;
- периоды обращения в настоящих пропорциях; по умолчанию земной год длится 30 секунд;
- при запуске каждая планета стоит там, где она находится сегодня;
- комета Галлея летит по своей орбите в обратную сторону, против планет; хвосты всегда направлены от Солнца и растут у перигелия;
- у каждой планеты освещена сторона, обращённая к Солнцу.

Что упрощено: расстояния сжаты, а планеты увеличены, иначе их было бы не видно.

**Заполнение контекста — как длинная выдержка.** В начале чата небо почти чёрное. Чем больше заполнен контекст, тем больше проявляется слабых звёзд, потом Млечный Путь и туманности.

**Ещё четыре сцены:** зимний вечер (сугроб растёт), ночная степь (звёзд больше, луна поднимается), цех на закате (домна разгорается), светлячки на лугу (светлячков больше).

## Установка

В терминале, в сессии Claude Code:

```
/plugin install tair-temy --marketplace TairTR/claude-cosmos-themes
```

Ответить `y` на «Add marketplace?», затем выбрать область (Enter — для всех своих сессий).

Или из обычной командной строки:

```
claude plugin install tair-temy --marketplace TairTR/claude-cosmos-themes
```

В десктопном приложении, где `/plugin` не работает: + рядом с полем ввода → Plugins → Add marketplace → `TairTR/claude-cosmos-themes` → Add plugin.

Нужна версия десктопного приложения, которая рисует фон за чатом. В новой сессии фон появляется после первого сообщения.

## Команды

| Команда | Что делает |
|---|---|
| `/tema` | следующая сцена по кругу |
| `/tema сбоку` · `космос` · `внутренние` · `снег` · `степь` · `цех` · `светлячки` | включить сцену |
| `/tema 90` | показать сцену как при 90% контекста |
| `/tema авто` | вернуть живое заполнение |
| `/tema год 5` | земной год за 5 секунд (`год реальное` — настоящее время) |
| `/tema сегодня` | вернуть планеты на сегодняшнюю дату |
| `/tema выкл` | выключить фон |

Клик по свободному месту фона в космических сценах переключает скорость времени. В строке статуса — дата по «часам» системы и сколько осталось до прилёта кометы Галлея.

У космических сцен есть тихий звук: включается значком динамика в заголовке сессии.

Если в системе включено уменьшение анимации, сцены стоят неподвижно.
